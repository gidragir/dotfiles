# Пошаговое руководство: Установка Windows 11 в Virt-Manager
## Шаг 0: Применение прав
Поскольку Ansible добавил вашего пользователя в группы `libvirt`, `kvm` и `virtshare`, эти изменения вступят в силу только после повторного входа в систему. **Обязательно завершите сеанс (Log out) и зайдите заново, либо просто перезагрузите компьютер.**
## Шаг 1: Подготовка файлов
Для установки вам понадобятся два образа:
1. **Образ Windows 11 (.iso):** Скачайте официальный образ с сайта Microsoft.
2. **Драйверы VirtIO (.iso):** Windows не знает о виртуальном оборудовании KVM, поэтому ей нужны драйверы для работы сети и быстрых дисков.
		- Скачайте стабильный релиз от проекта Fedora: найдите в сети `virtio-win.iso` (обычно первая ссылка на GitHub или документацию Fedora) и скачайте его.
## Шаг 2: Подготовка папки для диска (Специфика CachyOS / Btrfs)
CachyOS использует файловую систему Btrfs. Чтобы виртуальная машина не тормозила из-за функции Copy-on-Write (CoW), нужно заранее создать папку и отключить CoW для нее.
1. Откройте терминал.
2. Создайте папку для ваших виртуалок, например: `mkdir ~/VMs`
3. Отключите CoW: `chattr +C ~/VMs` _(Все диски, созданные внутри этой папки, автоматически унаследуют это свойство)._
## Шаг 3: Создание машины в Virt-Manager
1. Откройте приложение **Virtual Machine Manager** (Менеджер виртуальных машин) из меню приложений.
2. Нажмите иконку создания новой машины (монитор с плюсиком).
3. Выберите **Local install media (ISO image)**.
4. Нажмите **Browse...** -> **Browse Local** и выберите скачанный ISO-образ Windows 11.
5. Выделите ресурсы:
		- **RAM:** минимум 4096 MB (рекомендуется 8192 MB).
		- **CPU:** минимум 4 ядра.
6. На этапе настройки диска (Storage):
		- Нажмите **Select or create custom storage** -> **Manage...**.
		- Добавьте новый пул (кнопка `+` внизу слева), укажите путь к созданной папке `~/VMs`.
		- В этом пуле создайте диск (кнопка `+` вверху), размер не менее 64 ГБ. Выберите его.
7. **КРИТИЧЕСКИЙ МОМЕНТ:** На последнем экране перед нажатием "Finish" **обязательно поставьте галочку "Customize configuration before install"**.
## Шаг 4: Настройка эмуляции оборудования (Окно кастомизации)
Откроется окно с настройками оборудования. Сделайте следующее перед установкой:
1. **Overview (Обзор):**
		- В разделе _Firmware_ выберите `UEFI x86_64: ... edk2-ovmf` (обязательно с поддержкой **SecBoot** / Secure Boot).
		- Нажмите _Apply_.
2. **CPUs (Процессоры):**
		- Снимите галочку _Copy host CPU configuration_ (или оставьте, но убедитесь, что модель установлена на `host-passthrough`). Это даст виртуакле прямой доступ к инструкциям вашего процессора.
3. **Добавление TPM 2.0 (Требование Win11):**
		- Нажмите кнопку **Add Hardware** внизу.
		- Выберите **TPM**.
		- Model: `TIS`, Backend: `Emulated device`, Version: `2.0`. Нажмите _Finish_.
4. **Настройка диска на максимальную скорость:**
		- Слева выберите ваш диск (SATA Disk 1).
		- Измените _Disk bus_ на **VirtIO**.
5. **Подключение диска с драйверами:**
		- Нажмите **Add Hardware** -> **Storage**.
		- Device type: `CDROM device`.
		- Выберите ваш файл `virtio-win.iso`. Нажмите _Finish_.
6. **Сеть:**
		- Выберите _NIC_ слева.
		- Убедитесь, что _Device model_ установлена на **virtio**. _(Примечание: если после установки сети нет, см. Шаг 7)._
## Шаг 5: Установка Windows 11
1. Нажмите кнопку **Begin Installation** (Начать установку) в левом верхнем углу.
2. Запустится стандартный установщик Windows.
3. **ВАЖНО (На этапе выбора диска):** Установщик скажет, что не может найти диски. Это нормально, так как мы используем быстрый интерфейс VirtIO.
		- Нажмите **Загрузить драйвер (Load driver)**.
		- Выберите **Обзор (Browse)**.
		- Откройте CD-диск с драйверами (virtio-win), перейдите в папку `amd64` -> `w11`.
		- Выберите драйвер `Red Hat VirtIO SCSI`.
		- Диск появится, и вы сможете продолжить установку как обычно.
4. **Обход требования интернета (Экран настройки OOBE):** Windows 11 требует интернет для завершения установки, но драйвер сети VirtIO еще не установлен.
		- Когда появится экран "Давайте подключим вас к сети" (Let's connect you to a network), нажмите `Shift + F10` (на некоторых ноутбуках `Shift + Fn + F10`).
		- В открывшейся командной строке введите команду (без пробелов): `OOBE\BYPASSNRO`
		- Нажмите Enter. Виртуальная машина перезагрузится.
		- После перезагрузки на экране подключения к сети появится кнопка "У меня нет интернета" (I don't have internet). Нажмите её.
		- Выберите "Продолжить ограниченную установку" (Continue with limited setup).
		- Создайте локальную учетную запись.
## Шаг 6: Финальные штрихи (После установки)
Когда Windows 11 загрузится на рабочий стол, у вас, скорее всего, не будет интернета.
1. Откройте "Мой компьютер" внутри виртуальной машины.
2. Откройте CD-диск с драйверами (virtio-win).
3. Запустите файл **`virtio-win-guest-tools.exe`**.
4. Установите всё со стандартными настройками. Это добавит драйверы для сети, видеокарты, буфера обмена между хостом и виртуалкой, а также службу интеграции (qemu-guest-agent).
5. Перезагрузите виртуальную машину.
## Шаг 7: Решение проблем (Troubleshooting)
**Проблема: Отсутствует интернет после установки драйверов (IP-адрес 169.254.x.x)**
Это комплексная проблема, вызванная сбоем `dnsmasq` и блокировкой виртуального моста локальным файрволом CachyOS (UFW). Для восстановления доступа в интернет выполните следующие действия:
1. **Подтверждение использования адаптера VirtIO:** Убедитесь в настройках ВМ (раздел NIC), что модель устройства установлена строго на **`virtio`**. Эмулируемые адаптеры (вроде `e1000e`) создают лишнюю нагрузку на процессор хоста и увеличивают задержки. Мы будем использовать только нативный VirtIO.
2. **Постоянная разблокировка трафика в CachyOS (UFW):** _(Ansible-плейбук должен был применить эти правила автоматически. Если интернет по-прежнему недоступен, выполните их вручную в терминале хоста для фиксации настроек):_
		```
		sudo ufw route allow in on virbr0
		sudo ufw route allow out on virbr0
		sudo ufw allow in on virbr0
		```
3. **Настройка статического IP в Windows:** Для обхода проблемы с невыдачей адреса от встроенного DHCP, назначьте его жестко:
		- В Windows нажмите `Win + R`, введите `ncpa.cpl`.
		- В свойствах адаптера (Ethernet) откройте "IP версии 4 (TCP/IPv4)".
		- Выберите "Использовать следующий IP-адрес" и установите параметры:
				- IP-адрес: `192.168.122.50`
				- Маска подсети: `255.255.255.0`
				- Основной шлюз: `192.168.122.1`
				- DNS-сервер: `8.8.8.8`
## Шаг 8: Обмен файлами между хостом и виртуальной машиной (Virtio-FS)
Этот метод создает полноценный сетевой диск для двустороннего обмена на максимальной скорости.
**Подготовка директории на хосте:** Ansible-плейбук уже создал для вас безопасную директорию `/srv/Shared` с правами группы `virtshare`. Если вы настраиваете окружение вручную без плейбука, выполните на хосте:
```
sudo groupadd virtshare
sudo usermod -aG virtshare $USER
sudo usermod -aG virtshare nobody
sudo mkdir -p /srv/Shared
sudo chown root:virtshare /srv/Shared
sudo chmod 2770 /srv/Shared
```
**Настройка виртуальной машины (при выключенной Windows):**
1. В Virt-Manager откройте параметры виртуальной машины (иконка лампочки).
2. Выберите раздел **Memory** (Память) и **обязательно** поставьте галочку **Enable shared memory** (Включить общую память). Без этого шага машина не запустится. Нажмите _Apply_.
3. Нажмите **Add Hardware** -> **Filesystem**.
4. Укажите параметры:
		- **Driver:** `virtiofs`
		- **Source path:** `/srv/Shared`
		- **Target path:** `host_share` (Тег монтирования).
5. Нажмите _Finish_ и запустите Windows 11.
**Активация в Windows 11 (Устранение ошибки 1053):**
6. **Обязательная установка WinFSP:** Откройте CD-диск `virtio-win` в "Моем компьютере". Найдите в корне файл `winfsp-... .msi` (или зайдите в папку `virtio-fs`) и установите его. Без него служба не запустится.
7. Откройте "Диспетчер устройств" (Device Manager) -> Системные устройства. Убедитесь, что там появилось **VirtIO FS Device** без ошибок.
8. Нажмите `Win + R`, введите `services.msc` and нажмите Enter.
9. Найдите в списке службу **VirtIO-FS Service**.
10. Кликните по ней правой кнопкой мыши -> **Свойства**.
11. Измените _Тип запуска_ на **Автоматически**, затем нажмите кнопку **Запустить**.
12. Примените изменения. В «Моем компьютере» появится новый диск `Z:`, ссылающийся на `/srv/Shared`.
## Шаг 9: Настройка разрешения экрана и автоподстройки
По умолчанию разрешение экрана в гостевой системе может быть фиксированным и низким. Для включения плавного изменения разрешения при масштабировании окна Virt-Manager выполните настройки:
1. **Активация автоматического изменения размера:**
		- В окне запущенной ВМ перейдите в верхнее меню: **Вид (View)** -> **Масштабирование (Scale Display)**.
		- Поставьте галочку напротив пункта **Автоматически изменять размер гостя при изменении окна (Auto resize guest with window)**.
		- Убедитесь, что в меню **Вид (View)** параметр отображения задан как полноэкранный или стандартный, без принудительного фиксированного масштабирования.
2. **Проверка видеодрайвера (при выключенной ВМ):**
		- В настройках оборудования (иконка лампочки) выберите пункт **Video** (Видео).
		- Рекомендуемый тип модели: **Virtio** (дает лучшую производительность и плавность отрисовки) или **QXL** (резервный стабильный вариант).
## Шаг 10: Автоматизация SSH-туннеля и авторизация без пароля
Для проброса RDP-подключения до удаленной Windows-машины (которая доступна по VPN из гостевой ВМ) на хост CachyOS, используется технология SSH Remote Forwarding.
### 1. Настройка авторизации по ключам (Без пароля)
Чтобы туннель поднимался автоматически и без ввода пароля, необходимо сгенерировать SSH-ключ:
1. В гостевой Windows 11 откройте командную строку (`cmd` или `PowerShell`) и выполните команду:
		```
		ssh-keygen -t ed25519
		```
		_На все вопросы нажимайте Enter (не задавайте пароль на сам ключ)._
2. В CachyOS (на хосте) подготовьте директорию для ключей, выполнив в терминале:
		```
		mkdir -p ~/.ssh
		chmod 700 ~/.ssh
		touch ~/.ssh/authorized_keys
		chmod 600 ~/.ssh/authorized_keys
		```
3. Перенесите содержимое файла `C:\Users\Work\.ssh\id_ed25519.pub` из Windows в файл `~/.ssh/authorized_keys` на хосте CachyOS (можно использовать общую папку из Шага 8).
### 2. Конфигурация подключения и проброс портов
В Windows настроим SSH-клиент для удобного запуска одной командой:
1. Откройте блокнот в Windows и создайте файл по пути `C:\Users\Work\.ssh\config` (без расширения .txt).
2. Вставьте в него следующую конфигурацию (заменив `ваш_пользователь` на ваш логин в CachyOS):
		```
		Host tunnel
				HostName 192.168.122.1
				User ваш_пользователь
				RemoteForward 33890 10.2.104.222:3389
				IdentityFile ~/.ssh/id_ed25519
		```
**Использование:** Теперь в Windows достаточно открыть консоль и ввести `ssh tunnel`. Подключение установится мгновенно, а на хосте CachyOS станет доступен порт `33890`. Вы сможете подключиться к удаленному RDP-серверу (10.2.104.222) прямо из вашего Linux-окружения, подключившись RDP-клиентом (например, Remmina) к адресу `127.0.0.1:33890`.
